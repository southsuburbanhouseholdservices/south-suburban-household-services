# South Suburban Household Services Website

Final launch website built with React and Vite.

## Cloudflare Pages settings
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
- Root directory: `/`

## Add the business phone number later
Open `src/siteConfig.js` and place the number inside the `phone` field. The current website intentionally displays “Coming soon” until the number is available.

## Local development
```bash
npm install
npm run dev
```
